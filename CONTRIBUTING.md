# Contributing

Thanks for your interest in contributing.

## Reporting issues

Open a GitHub issue with a clear description of the problem or proposal, the steps to reproduce it if it is a bug, and the environment you are running in. For security reports, do not open a public issue — see SECURITY.md for the private reporting route.

## Proposing changes

1. Fork the repository and create a topic branch for your change.
2. Keep the change focused; describe the motivation in the pull request.
3. Make sure the existing tests pass, and add tests for new behaviour.
4. Open a pull request against the default branch. Changes are reviewed before merging.
